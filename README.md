# Gen AI Projects

This repository contains my six Gen AI projects.

### 01. LLM Powered Chatbot

A chatbot application powered by a Large Language Model.

### 02. RAG PDF Chatbot

A Retrieval-Augmented Generation chatbot for interacting with PDF documents.

### 03. LangGraph MCP Expense Tracker

An expense-tracking project using LangGraph and MCP.

### 04. Multi-Agent Customer Support

A multi-agent customer support system using LangGraph.

### 05. RAG-Based Knowledge Assistant

A Retrieval-Augmented Generation application that retrieves relevant information from a knowledge base and generates accurate responses using an LLM.

### 06. GenAI-Powered Indian Railways Administrator

A GenAI-based administrator assistant using a supervisor-driven multi-agent architecture to retrieve and answer ticket and transaction-related information from a structured database.
